# LunchPool 规格说明（示例项目）

LunchPool 让一群同事合买一顿午餐。

## 角色

- 组织者（organizer）：部署者。只有当前组织者可以把组织者身份交给别人。
- 用餐者（eater）：向合约存入 ETH 的任何地址。
- 商家（vendor）：组织者在结算时指定的收款地址。

## 规则

1. 每次出资不少于 0.001 ETH。
2. 出资和自助退款只能在截止时刻 `deadline` 之前进行，截止时刻当秒不再允许。
3. 每个用餐者只能取回自己的出资。
4. 截止之后，组织者二选一：`payVendor` 把资金付给商家，或 `cancelAll` 把资金退还给所有用餐者。
5. 任何一位用餐者的行为都不能阻止其他用餐者拿回资金。

## 信任假设

- 组织者诚实地选择商家。组织者作恶不在本次范围内。
- 合约只持有 ETH。

## 不变量

- `total` 等于所有 `paidBy` 之和（结算前）。
- 合约余额不小于 `total`。
