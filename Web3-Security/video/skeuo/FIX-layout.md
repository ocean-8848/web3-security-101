# 修复已交付各集的遮挡问题

频道主 2026-11-15 要求：查出已交付各集里的遮挡问题，然后修复。

版面检查的报告已经跑好，在 `hf/out/lint/<集>-<段>.txt`。每行格式是：时间段、第几句、问题类型（重叠 / 出框 / 截字）、涉及的两个元素（类名「文字」）、重叠比例或位置。`cap「…」` 是字幕，字幕是渲染后才叠上去的，固定在画面底部居中，卡片底边离画面底 84 px，高约 78 px。

## 先分类，再动手

每条问题归到下面一类：

1. **要修：看得见的遮挡**
   - 标签、卡片压住字幕，或者被字幕压住（常见于画面底部的旗子标签、地名标签）。
   - 卡片或术语卡盖住了还在讲的标签或代码。
   - 两个都要读的标签互相压住超过约 15%。
   - 标签被画面边缘切掉，并且持续 1 秒以上（出框）。
   - 截字。
2. **顺手修：看不见但不干净**
   - 新标签替换旧标签、两者在同一位置（重叠约 100%），旧的没淡出。给旧标签补一个 0.2 秒淡出，时间放在新标签出现时。
3. **有意叠放，不改画面，只加标记**
   - 占位格被填进来的卡片盖住、调用栈层层叠起、刻意排成一摞的卡片。给相关元素（或它们的共同父元素）加属性 `data-layout-allow-overlap`，版面检查以后会跳过。
4. **可以忽略**
   - 只出现在一个采样点（时间段的起止相同，比如 `30.5–30.5s`），而且正处在镜头移动或淡入淡出中。

## 怎么修

- 改 `segN/src/build-story.mjs`（或它引用的 `layout.mjs`），用 **Edit 小改**，不要整份重写。
- 常用改法：把标签换个锚点方向（`wlab` 的 `anchor`：b / t / l / r）；把标签挪到物件另一侧；把靠近底部的标签往上提，离开字幕区（屏幕 y 约 900 以下就是字幕区）；让旧标签在新卡片出现前淡出；术语卡被挡时改用 `low: true` 或调整出现时刻。
- 时间查法照旧用 `kit/timing.mjs` 的 `wordAt` / `lineAt`。
- 每改完一段：
  1. `node src/build-story.mjs`
  2. `npx hyperframes check`，不能有 error。
  3. `node ../../tools/layout_lint.mjs .`，确认要修的问题都消失了。剩下的应该只有第 4 类。
- **看图有上限**：整集最多看 8 张图。先靠报告里的元素名和时刻判断，只有拿不准是不是真遮挡时，才用 `npx hyperframes snapshot --at <秒>` 看那一帧，或者从 `out/<段>.mp4` 用 ffmpeg 抽一帧缩到 960 宽看。
- **不渲染**：你只改源码、跑 check 和版面检查。渲染、叠字幕、拼接、预览由统筹统一跑。
- **不许用 pkill / killall**。
- 只改本集目录，不改共用的 `kit/`、`tools/` 和其他集，不提交 git。
