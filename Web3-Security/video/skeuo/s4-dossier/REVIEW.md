# REVIEW · s4-dossier（调查纪录片 / 案卷）

## 创作选择
- 整片是一张灰绿呢面桌（#c9cbbf + 细纤维纹），所有文件都是桌上的实物，镜头 #cam 是一个由 `camera(t)` 纯函数驱动的整体平移/缩放（关键帧 + power2.inOut，1.0–1.4 s），不用剪切。长途转场（钥匙纸 → 流程纸）中途拉远到约 0.45× 再推回，交代"这些文件在同一张桌上"。
- 高潮：20.4–21.7 s 镜头推到 1.55×，`operation` 打出后空 0.67 s，21.85 s 打出粗体 `1`，0.35 s 红圈，再红笔写 `DELEGATECALL`，铅笔补"正常转账 = 0（CALL）"。全片红色只出现在此、l6 连线、④ 圈注。
- 片头卡是一张贴胶带的标签纸落在流程纸上，下面露出被红圈的 ④，主副标题打字完成于 44.62 s，之后 2.54 s 完全静止。
- 没做的版本：真实照片质感（相片里放截图素材）；以剪切代替镜头移动的"幻灯式"案卷。
