统一视觉（画面、物件、颜色、字幕、术语卡、结束卡、版面分区、独立成片）见 `PIPELINE.md` 第 0 节，这里不重抄。讲稿 `script.json`，多音字表 `pron.json`。

## 1. 本集骨架

- **一句话核心观点**：交易所同时是保管者和检查站。保管者这一面，钱从充值地址经归集进热钱包，提币从账本经风控、签名服务从热钱包发出；最危险的不是私钥被偷，而是入账被假充值骗过、签名服务被伪造的上游请求驱动。检查站这一面，制裁筛查、链上风险评分、Travel Rule、反洗钱监控跑在同一条充提链路上，失守的代价最终回到交易所身上。暂停提现不等于撤销权限。
- **支撑结构**：
  1. 钩子：2026 年 10 月 29 日 Binance 热钱包一条链接一条链被转出；暂停提现没挡住全部未授权转账，最后一笔 23:56（UTC）；约 63.4 亿美元（项目方）；称未发现私钥泄露；预测题：提现已停、热钱包服务已关，带着恶意 EIP-7702 委托的以太坊热钱包，新转入的钱安全吗？
  2. 准确表述 + 机场比喻（不成立处：链上流向永久公开）→ 托管流转：充值地址 → 归集 → 热钱包；冷 → 温 → 热补充；超出水位回冷钱包；链下流水线：充值扫描 → 账本 → 风控引擎 → 签名服务 → 热钱包 → 四个攻击点 + 内部人。
  3. 假充值六种形态（失败上链 / Omni valid / XRP 部分支付 Bitfinex 案 / 假代币 / 伪造事件 / 回滚）→ 原则：以链上执行结果和实际到账金额为准 → 四道入账检查 + 第二独立节点 → 新链从头设计。
  4. 签名服务只认格式 → Bitget（零日、伪造提现指令、项目方称排除私钥泄露）→ Binance 路径（Homebrew → 假面试作业 → AI 工具 → 部署令牌 → 签名服务 → EIP-7702 委托 / 普通转账）→ 长期部署令牌是决定性一环 → 三条防线。
  5. 检查站：攻击者只需规则有漏洞 → 四道关（制裁筛查、链上风险评分、Travel Rule、反洗钱监控）→ 门槛（FATF 1000 / 欧盟服务商间不设门槛）→ 冻结是最后机会（Tether、Circle；原生资产不能由发行方冻结）→ 代价（Binance 约 43 亿美元认罪、KuCoin / OKX）→ 误报与申诉 → Tornado Cash 移出名单 ≠ 风险消失。
  6. 回答预测题（不安全；委托独立于链下系统；10 月 30 日 00:10 才清零，存活约 3 小时 50 分）→ 暂停不等于撤销 → 交易所三件事 → 用户侧防护 → 收束。
- **关键术语**：托管、热钱包 / 温钱包 / 冷钱包、归集、水位、充值扫描、内部账本、风控引擎、签名服务、假充值、执行状态、部分支付、代币合约白名单、确认数 / 回滚、独立节点、零日漏洞、部署令牌、EIP-7702 委托、制裁筛查、OFAC、链上风险评分、混币器、Travel Rule、反洗钱（AML）、辖区门槛、发行方冻结、无牌汇款、分链熔断、提币白名单、冷却期。
- **成立条件、例外和风险**：比喻不成立处 seg2 L10–L11。seg4 Binance 路径只画到"访问内部签名服务、签出委托"这一层机制，不画脚本内容、不写令牌权限细节（初步报告未公开）；Bitget 受影响的安全产品没有公开名称，画面只写"第三方安全产品"。seg3 只讲入账校验的缺口和正确做法，不演示构造假充值交易的步骤。seg5 Tornado Cash 只讲制裁状态变化与风控含义，不讲刑事案件进展。seg4 L19 "冷热隔离和私钥保护都挡不住"、seg6 L15 收束句是解读。

## 2. 世界与主角（全片固定）

一个连续的等距世界，叫"**一座交易所机场**"。一条浅灰石板路沿 u（左→右）贯穿，钱从左边的链上进来，往右流过金库、签名间，最右是合规检查站和用户柜台。从左到右：**入境口 · 充值**（A）→ **金库区**（B）→ **签名间**（C）→ **合规检查站**（D）→ **用户柜台**（E）。每区上方挂一块 E01 `signBoard` plate 作为"机场指示牌"（seg2 机场比喻时逐块亮起）：A "入境口 · 充值"、B "金库 · 冷钱包"、C "登机口 · 提币"、D "安检 · 边检"、E "用户柜台"。

主角是 B 区那只 **以太坊热钱包**：kit `safe` variant hot（铭牌 "ETH 热钱包"），旁边立一根 E02 `addrPlate`（`text` "热钱包地址"），立柱上挂 E15 `delegateTag`（`prefix` "0xef0100"、target "攻击者合约"，红色）。钩子里它被清空；seg4 讲签名被驱动时委托挂牌挂上去；seg6 回答预测题时镜头回到它，挂牌被清零、换成灰色空牌。攻击者一律 kit `person` role attacker；工程师 role engineer；普通用户 role signer。
