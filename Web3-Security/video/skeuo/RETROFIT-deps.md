## 四类规则

### 1. 不出现检查清单编号

- 画面里不写 REN-1、MPC-2、SIG-3 这类检查项编号，只写动作本身，例如"列出所有外部调用"。

### 2. 术语卡

术语第一次出现时，如果配音没有当场解释，就在画面上弹出一张术语卡。

卡片规格：

| 项目 | 规格 |
|---|---|
| 位置 | 左上角，约 (48, 120)，避开胶囊和字幕 |
| 底色与边框 | 白底，青蓝左边框 6 px，圆角 12 px |
| 宽度 | 不超过 560 px |
| 第一行 | 术语，Noto Sans SC 900，32 px |
| 第二行 | 一句话定义，700，28–30 px，不超过 24 个字 |
| 出现时机 | 说到这个词时出现，停留 3–4 秒 |
| 数量 | 同一时间只显示一张 |

ep07 的 seg1–seg5b 已经按这个规格做好，可以直接参考它们的源码。

判断哪些词要出卡：
1. 通读本集讲稿，凡是普通观众未必懂、而配音第一次出现时没有当场解释的术语，都要出卡。

## 做法

1. 逐段改 `src/` 源码，然后重新生成。时间用 `kit/timing.mjs` 的 `wordAt` / `lineAt` 查。ep29 的时间查法见下面的单独说明。
2. 渲染前，在每张新术语卡、每个改过的标签处各抽一帧确认。要检查：不压字幕、不压胶囊、不和别的卡重叠、字没被截断。`npx hyperframes check` 不能有 error。
3. 重新渲染所有改动过的段，复制到 `out/`。
4. 在 `hf/` 目录运行 `python3 tools/concat.py epNN`，重新生成完整版。
5. 生成 720p 预览，不超过 30 MB：
   ```
   ffmpeg -y -i out/epNN-full.mp4 -vf scale=1280:720 -c:v libx264 -preset slow -b:v 270k -maxrate 400k -bufsize 800k -c:a aac -b:a 64k -ac 1 -movflags +faststart out/epNN-full-preview-720p.mp4
   ```
6. 最后核对字幕，下面两条命令的结果都应为 0：
   - `grep -c "以后单独讲\|手册\|本章" out/epNN-full.srt`（ep03 的"规程手册"是道具名，不计）
   - `grep -c "[A-Z]\{2,5\}-[0-9]" out/epNN-full.srt`（只统计清单编号，ERC-20 这类标准名不计）
