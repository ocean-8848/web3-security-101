成片：`renders/seg3.mp4` → `../out/seg3.mp4`（157.72 s，1920×1080，配音轨）。
生成：`node src/build-story.mjs` → `compositions/story.html`；布局 `src/layout.mjs`（import seg1 的 `VEND` / `ROAD`），自补小件 `src/props.mjs`。kit / kit-ext 只 import 未改。
抽帧工具：`review/shots.sh <dir>`（段首 0.8 s + 每句中点 + 段尾 −0.5 s）、`review/grid.py <dir>`（带时间标签的 2×2 拼图）。

## 世界与镜头
- 世界坐标对齐 seg1：售货机 (0,0)，交易之路中线 v = 330 沿 +u。路上从西南到东北：用户/攻击者 → 笔记本（钱包与前端）→ 内存池 → 分拣机 → 售货机（目标合约）→ 右侧代币 / DEX / 预言机 → 东北段跨链桥 → 对岸售货机。路前方 v = 820 一排六块挂牌；⑥ 两侧更远处是 L21 的两块木牌。
- 镜头一律用 `fit(点集)` 按包围盒自动取景（屏幕安全区 x 110–1810，y 165–880，避开胶囊和字幕卡），每类漏洞（L14–L18）各有一个推近机位。

## 自审改过的问题（按轮次）
1. 第一轮：手写机位使主体偏上、下半屏空，站点镜头太远（主体远小于画面 40%）→ 改为包围盒取景，站点镜头放大到 1.2–1.4。
2. 用户与攻击者重叠、"一笔交易"标签压在攻击者身上 → 攻击者移到用户左下。
3. 六块挂牌宽度 380、间距 400，连成一道"栅栏"读不出是六块牌 → 宽 340、间距 440；牌面文字改成反向缩放的 HTML（任何相机倍率下 ≥ 30 px）。
4. 挂牌段整体广角时细节太小 → L14–L18 每句推到"该类挂牌 + 对应物件"。
5. 底层（L11）土层太薄、读不出"地面剖开"→ 土层加厚到 110，红虚线标出切口；标签移到底层平台前沿，不压内存池。
6. 预言机表盘、售货机顶多次钻进右上胶囊 → 相关机位把它们纳入取景点、安全区上沿下移。
7. L21 木牌被前方物件挡字 → 物件放到木牌斜下方；AI 放大器两条虚线终点改到牌顶边，不压牌面字。
8. L19 "前端篡改"标签出画 → 取景点加入笔记本标签宽度；去掉攻击者点，画面放大，挂牌文字不再溢出牌面。
9. L20 Euler 连线穿过清单卡 → 清单卡放左、Euler 卡放右，红线直达 Euler 卡。
10. "回调 → 重入""合约写得再对也没用""规格可被套利"标签与物件或字幕区重叠 → 改锚点位置。
11. L4 区块箱在到达售货机前就淡出 → 延到"业务逻辑"前才收进机器。
12. 金币堆的接触阴影在隐藏期间留下灰斑 → 整组初始隐藏。
13. `check` 报帧 0 隐藏态不生效 → 初始隐藏改用 `gsap.set`（同时保留时间线 0 秒处的 set）。
14. 钥匙掉落用的 y 弹跳与 grow 的 scaleY 同时作用在一个元素上，有反向 seek 风险 → 去掉弹跳；⑥ 挂牌脉冲改到 HTML 字上。

## 保留的警告
- `dead_stretch` 25.28–28.70 s、30.81–33.97 s：这两段的动作在 `#cam` 内的 SVG 属性上（齿轮、管道流动、表盘指针），取样器看不到（kit README 已知事项）。
- `clip_media_fit`：配音 157.64 s，槽位 157.72 s，尾部 0.08 s 静止画面，无影响。

## 事实核对
屏幕文字只用讲稿和 BRIEF 中的词：五个信任边界、回调 → 重入、顺序可被利用、图上没画共识层与节点、六大类名称与关键词、Euler = ⑤ 业务逻辑缺陷 + ④ 闪电贷放大（手册第 01 章原文同）、"只打勾不够"（手册"不能只按清单逐项打勾"）、⑥ 拆成"链与基础设施""人、设备和流程"、社工 = 入口、私钥 / 前端 = 落点、AI = 攻防两边的放大器。Bybit 小图只画保险柜 + 钥匙，标"多签私钥"，未加第 01 章之外的细节。
