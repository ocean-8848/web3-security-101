## 1. 本集骨架

- **一句话核心观点**：许可链把"谁能参与"从密码学和经济问题变成了身份和治理问题。攻击者不需要多数算力，只要一张有效证书、一把管理员密钥，或几家成员共谋。门禁挡住外人，风险在门里面：发证书的人、拿管理员密钥的人、达到门槛的成员、没人维护的软件，以及规则本身的实现。
- **支撑结构**：
  1. 钩子：Fabric 交易交联漏洞：区块哈希不变，节点解析出不同交易，世界状态分歧；人人持有效证书，账本照样分叉。问题：只让熟人进门的区块链，风险在哪？谁能写、谁能看、谁能改规则？
  2. 准确表述（许可链、联盟链）→ 写字楼工牌比喻（不成立处：多数成员能合法重写状态，账本看不出作恶）→ 按控制资源排入口 → Ronin 反例：许可集合小，攻破门槛也低。
  3. Fabric：执行—排序—验证三道关 → 背书策略（多数 vs 任一组织）→ 排序：Raft 只防宕机，BFT 防作恶并分运营方 → 私有数据：只留哈希，低熵要加盐，transient 传入 → 链码确定性。
  4. 治理与密钥：根 CA 离线 + HSM + 中间 CA；管理员集中；配置更新多签与成员退出吊销（身份不自动过期，演练）；成员共谋 → 外部锚定（证明历史未改，不证明数据为真）；单一云。
  5. Corda 与 Besu：Corda 点对点 + 公证人（单节点公证人可双签 → 集群分运营方）+ Flow 数据先校验 + always-accept 不进生产；Besu QBFT 漏洞（一名验证者增发原生币，3f+1 救不了实现缺陷）+ P2P 端口 DoS + 本地准入一致；GoQuorum / Tessera 退役。
  6. 收尾：三种角色各一件事 + 用户三个问题 → 回答开头 → 成立前提 → 收束 + "这个系列就到这里"。
- **关键术语**：联盟链、许可链、世界状态、根 CA、链码、背书、读写集、排序服务、崩溃容错、BFT、私有数据集合、随机盐、HSM、中间 CA、吊销、外部锚定、公证人、双花、拜占庭验证者、准入。
- **成立条件、例外和风险**：比喻不成立处 seg2 L9–L12。解读（灰标签"解读"）：seg1 L9 后半（"同一串字节只能读出同一组交易"是对"哈希编码必须无歧义"的改写）、L11；seg4 L8；seg6 L9–L13。**只讲机制与防御**：交易交联只画"同一哈希 → 两种解析 → 两份账本"，不画如何重组字节；Besu 只画"一名验证者 → 凭空多出原生币"和"大体积提案堵住线程"，不画报文。
- **不确定之处**：见文末"事实口径"。

### seg1 ① 同一个哈希
目标：观众能说出"Fabric 的一个漏洞让区块哈希不变、节点却解析出不同交易，人人持有效证书，账本照样分叉"，并带着"只让熟人进门的区块链，风险在哪"往下看。
