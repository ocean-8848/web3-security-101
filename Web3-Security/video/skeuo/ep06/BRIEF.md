## 1. 本集骨架

- **一句话核心观点**：EVM 只有整数，每一次除法都会丢掉余数；丢掉的余数归谁，决定了谁能从协议里慢慢抠出钱。规则只有一条：余数归协议，不归调用者。
- **支撑结构**：
  1. 钩子：Balancer V2（2025 年 11 月）单步很小的取整误差，在一笔批量交换里被累积；猜题"1.5 单位向下收款，重复 1000 次多拿约 500"。
  2. 五类缺陷：溢出（BEC batchOverflow）、截断、先除后乘（7×3÷5）、单位不一致（三条链上的 USDT 精度）；舍入方向留到下一段。
  3. 舍入方向：ERC-4626 四个函数的取整方向；往返套利；披萨比喻和它不成立的地方；Balancer 与 KyberSwap 两个案例；对"重复 N 次"做模糊测试。
  4. 金库通胀攻击：份额公式 + `totalAssets` 读余额 → 捐赠抬价 → 受害者 0 份额；成立条件（金库几乎为空）。
  5. 防御：虚拟份额与偏移、初始存款销毁（含 Uniswap V2 的 1000 份最小流动性）、内部记账、最小份额检查；修复要两个结果；Uranium 分叉常数漏改；今天能做的事 + 回答开头。
- **关键术语**：溢出 / 下溢、回绕、`unchecked`、类型截断、`SafeCast`、先除后乘、`mulDiv`、舍入方向（向上 / 向下）、`decimals()`、ERC-4626、份额（shares）、资产（assets）、`deposit / mint / withdraw / redeem`、往返套利、不变量、捐赠、通胀攻击、虚拟份额、`decimalsOffset`、死地址、最小份额检查、模糊测试。
- **成立条件、例外与风险**：
  - 0.8 默认检查溢出，但 `unchecked`、内联汇编、类型转换、移位不在其中。
  - 先乘后除本身也可能溢出，所以推荐 `mulDiv`（512 位中间结果，可指定方向）。
  - 往返套利要"单次误差 > 单次成本"：手册写的是"没有手续费的场景下"可循环上千次。
  - 通胀攻击只在金库几乎为空时有效；攻击成本 = 捐赠额；受害者存款接近捐赠额才有利可图。
  - 虚拟份额不是让攻击不可能，而是让同样损失需要 10^offset 倍的捐赠。
  - 披萨比喻在两处不成立：披萨店会被投诉；合约里同一操作能在一笔交易里重复几千次（讲稿 seg3 L14–L15 已说）。
- **不确定之处 / 口径**（屏幕上用灰标签标出）：
  - Balancer：约 9480 万美元 = 官方复盘、事发时估值、只含 Balancer 部署的池子；约 1.28 亿美元 = 早期第三方分析（Check Point Research）。"批量交换里串联小额交换""操纵不变量和 BPT 价格"是公开分析口径；"exact-out 路径取整错误"是官方复盘口径。两个数字同屏时必须同时挂口径标签。
  - KyberSwap 约 5620 万美元 = 官方复盘称"受影响资产"，不要写成"被盗"。
  - BEC"多家交易所暂停充提"、Uranium"约 5000 万美元"= 公开报道；Uranium"手续费 0.3% → 0.16%"= 公开分析报告。
  - seg1 的 1.5 单位猜题、seg2 的 7×3÷5、seg4 的 1 万 / 9999 USDC 都是手册给的**示例数字**，挂灰标签"示例"。
  - seg3 L7"给出去的向下，收进来的向上"、seg5b L8–L9 属于解读，挂灰标签"解读"。
  - 只讲机制，不画真实攻击交易、地址、哈希。

## 2. 世界与主角（全片固定）

一个连续的等距世界，叫"**整数工坊**"。从左到右：

1. **左区·溢出车间**（seg2 前半）：一台合约机器（ep03 `contractMachine`，铭牌 "BEC"）+ 机器顶上叠一个里程表计数器（ep02 `rollCounter`）表示 256 位整数；旁边是 ep03 的 `slotCabinet`（只用 1 个抽屉）讲截断和移位。
2. **中区·取整台**（全片主角）：一台**取整刀**（新补，见下表）。金条或点阵推进刀床，刀落下，余数碎屑掉进两个托盘之一：青蓝托盘"协议"或红托盘"调用者"。刀侧的方向拨杆标"向上 / 向下"。seg1、seg3、seg4 都回到这里。
3. **中右区·金库**（seg3–seg5a）：kit `safe`（打开时露出金条 = 资产）+ 贴在保险柜 −u 侧的**份额出票机**（新补），出票口吐出**份额凭证**（新补）。金库门牌挂 "ERC-4626"。
4. **右区·池子与分叉**（seg1、seg3、seg5a）：ep01 `sorter`（分拣机 + 区块箱）表示"一笔批量交换"，带上一排小信封（ep01 `letter`）= 很多笔小额交换；ep01 `balance` 天平 = 池子不变量。
5. **远景·跨链**：两段 kit `chain` 中间一座 ep01 `bridge`，桥两端各放一把**精度刻度尺**（新补），seg2 L23–L28 用。

开场镜头在右区（Balancer 池子），结尾回到右区，形成闭环。

## 4. 各段分镜（按句写；句号见 timing.json 的 lines，从 0 开始）

### seg1 ① 一次只错一点点（63.6 秒）
目标：观众能说出"Balancer 的损失不是一次大错，而是一笔交易里累积了很多次很小的取整误差；余数归谁，决定谁能抠出钱"。
- L0 Balancer 稳定池：镜头在右区，一台合约机器（铭牌"稳定池"）从地面长出，旁边一个事件卡"2025 年 11 月 · Balancer V2 · 多链"。机器里的金币（点阵）开始一枚枚往外流。
- L1 约 9480 万美元：事件卡下方加一行大字"约 9480 万美元"，紧跟灰标签"官方复盘 · 事发时估值"。
- L2 根因是取整：镜头横移到中区，取整刀第一次亮相，铭牌标签"取整"（青蓝），刀抬起。
- L3 单次误差很小：一根金条（点阵 15 格）推进刀床，刀落下，切下的碎屑只有 1 格，碎屑掉进**红托盘"调用者"**。镜头推近碎屑，标签"1 个最小单位"。
- L4 串进一笔批量交换：镜头回到右区，分拣机的传送带上排满几十封小信封（ep01 `letter`），全部进入同一个区块箱，箱盖合上，标签"一笔批量交换"。
- L5 误差朝自己累积：每一封信封进箱，取整刀小窗（画中画，右下）就落一次刀，红托盘里的碎屑堆一层层长高。**本段关键画面**：一笔交易的箱子 + 一摞越来越高的红色碎屑。
- L6 先猜一道题：画面清场到取整刀，灰标签"示例"；刀床上方一个点阵卡"1 份额 = 1.5 单位"（1 个实心点 + 半个点）。

### seg2 ② 五类缺陷（151.6 秒）
目标：观众能说出五类缺陷的名字；能复述 BEC 里 2 × 2^255 回绕成 0 让余额检查失效；记住"先乘后除 / mulDiv"和"从合约读 decimals"。
