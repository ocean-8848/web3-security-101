## 1. 本集骨架

- **一句话核心观点**：合约如果用"同一笔交易里能被改变的数据"定价，攻击者就能借一大笔钱改掉它、按错价交易、再还钱；换成抗操纵的价格源之后，还要防价格过时、撞上下限和配错。
- **支撑结构**：
  1. 钩子：Moonwell（2026 年 2 月，Base）把 cbETH/ETH 汇率当成美元价，约 2200 美元报成约 1.12 美元；正值和时效检查都会通过。
  2. 闪电贷让本金不再是门槛；当铺比喻及其不成立处；一笔交易内可变的读数 = 攻击者的输入参数。
  3. AMM 现货价：恒定乘积、示例池推高 9 倍、五步路径、利润构成、浅池风险；bZx、PancakeBunny、Cream。
  4. 三类价格源：TWAP（Inverse 多区块操纵）、链下聚合（心跳、偏离阈值，风险是过时与上下限）、多源组合；LP 公平储备；"价格错了 / 停了会怎样"。
  5. 安全读取：正值、时效、上下限、精度；Venus 与 LUNA 下限；latestAnswer、按喂价心跳、降级路径、拉取式预言机；L2 排序器在线状态 + 宽限期。
  6. 今天能做的事；回答开头；收束。
- **关键术语**：预言机、闪电贷、现货价、恒定乘积、滑点、储备、LP 代币、金库份额价格、捐赠、TWAP、链下聚合、心跳、偏离阈值、上下限（minAnswer）、精度（decimals）、`latestAnswer` / `latestRoundData`、降级路径、拉取式预言机、置信区间、排序器、强制提交、宽限期、坏账、抵押率、供应上限、健康度。
- **成立条件、例外与风险**：
  - 闪电贷"出借方无风险"只指本金：没还上，整笔交易回滚。
  - TWAP 挡单笔操纵，不挡有资本的多区块操纵；PoS 下同一提议者连续出块时成本下降。
  - 链下聚合价格一笔交易改不动，但会过时、会停在上下限、节点和喂价方会失效。
  - 正值 + 时效只证明价格存在且新，不证明它对；要上下限或第二价格源比较。
  - 宽限期 1 小时只是示例；喂价地址部署前按官方文档核对（画面不写地址）。
  - 当铺比喻不成立处：现实要几天，链上在同一笔交易里（seg2 L16–L17 已说）。
- **口径**（屏幕上用灰标签标出）：
  - Moonwell：约 2200 → 约 1.12 美元、1096.317 枚 cbETH、约 178 万美元坏账 = The Block 报道。画面可写"1096.317 枚"。
  - LUNA 喂价下限 0.10 美元、Venus 约 1100 万美元 = 公开报道。
  - bZx 约 95 万、PancakeBunny 约 4500 万、Cream 约 1.3 亿、Inverse 约 1560 万美元 = 公开报道。
  - latestAnswer 不含时间戳 = Chainlink API 文档；排序器在线状态喂价 = Chainlink 文档；Mantle 强制提交最长 12 小时 = L2BEAT（截至 2026 年 11 月）；拉取式预言机检查 = Pyth 文档。
  - 示例：当铺比喻（比喻）、1000 ETH / 200 万 USDC 池子、抵押率 75%、LUNA 市场价 0.01、宽限期 1 小时。
  - seg6 L11 的"窗口"一句属于解读。

### seg2 ② 借来的本金
目标：观众能说出"闪电贷借还在同一笔交易里，所以不需要本金"，以及"一笔交易内可变的读数都是攻击者的输入"。
**关键画面**：L4 青蓝"一笔交易"框整体回滚复原；L22 规则牌"一笔交易内可变 = 攻击者的输入"立在 AMM 池前。
- L0 两个词：镜头在中区借贷合约；两个空白词卡位。
- L1 预言机：价格管从借贷合约伸到右区报价机，管内价格小签（数字）流向合约；词卡"预言机"填上。
- L2 通常是价格：报价机表盘亮，读数"价格"。
- L3 闪电贷：镜头左移到 `flashDesk`，词卡"闪电贷"；`frame:true` 青蓝"一笔交易"框罩住柜台；三个小标签沿框顺序亮"借款 → 使用 → 还款"。
- L4 没还上就回滚：金条从柜台搬出又倒放回原位（时间倒带效果，框闪一下），标签"未还 → 整笔回滚"。**关键画面**。
- L5 不需要抵押：柜台上方一个空的抵押托盘，标签"无需抵押"。
- L6 本金不是门槛：一道小门槛木条（`signBoard` 横放）被红线划掉。
- L7 全部流动性：柜台金条点阵全部亮起，`person` attacker 站到柜台前。
- L8 当铺比喻：镜头下移到左前集市街：`marketStall` 与 `tellerCounter`（招牌"当铺"）隔街相对；当铺上方一根虚线指向黄金摊价目牌，标签"按最新成交价估值"；灰标签"比喻"。
- L9 借来 1 亿：`person`"你"从"朋友"手里接过一叠金币点阵"1 亿"。
- L10 高价买光：价目牌数字变红变大，摊上金条全部搬到"你"身边（`marketStall` attacker）。
