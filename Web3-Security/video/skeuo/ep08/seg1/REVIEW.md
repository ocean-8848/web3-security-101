# seg1 ① 新鲜的错价 · 自审

## 做了什么
- `src/build-story.mjs` 生成 `compositions/story.html`。世界坐标全部取自 `shared/layout.mjs`（未改动）。本段只在本地另加了几个位置：`COUNTER`（滚动计数器，在借贷合约右前方）、机器人间距和抵押币偏移、报价机正面两个进料口的高度。
- 0–1.6s 是标题卡「① 新鲜的错价 / Moonwell 的错价」，胶囊停在 ①。
- L0：治理提案文件落到报价机旁并盖章，配事件卡「2026 年 2 月 15 日 · Moonwell · Base」。
- L1–L2：左口接 cbETH/ETH 汇率（青蓝，管内有流动），右口是 ETH/USD 红虚线断口，配红叉和「汇率 ≠ 美元价」。
- L3：cbETH 硬币出现，指针落到底，标出 ≈ 1.12 美元（红）和「真实 ≈ 2200 美元」（灰），来源卡写「The Block 报道」。
- L4：镜头移到中区，3 台 liqBot（小屏显示 $1.12）开进来，夹走 3 枚 cbETH 后离场；计数器从 0 滚到 1096，标签写「清算 ≈ 1096.317 枚 cbETH」。
- L5：账本闪一下，标出「坏账 ≈ 178 万美元」。
- L6–L10：「先猜」卡之后回到报价机，出现两张检查卡「价格 > 0」和「刚刚更新」（时钟走动）。先打「?」，再盖绿勾，边框变绿。最后读数闪红，出「新的 ≠ 对的」。
- L11：镜头拉到 CAMS.wide，三处依次挂标签：AMM 池「可能被推高」（指针甩到红区）、时钟「可能停住」、断口「可能配错」。
- L12：镜头回到 CAMS.center，右侧出现空白代码行卡「哪一行代码拦住它？ / ?」，用灰虚线连到借贷合约和价格管的接口；约 62.4s 之后画面静止。

## 没解决 / 说明
- 没画 METER（下限量筒，LUNA 用）和 oracleGhost：BRIEF L3 写的是「oracleGhost 关闭」，只让墨色指针落到底；量筒在 oracle 近景里会挤占读数标签的位置。seg4、seg5 需要时自己放，位置照 layout.mjs。
- 没画 GOLD 点阵金条堆和 AMM_ALT，seg1 不用。
- 「≈ 1.12 美元」按「1.12」这个词的估算时刻弹出，比字幕「只值约 1.12 美元」略晚，因为 words 是估算值。
- 「cbETH 抵押品」标签在机器人到位的约 0.5s 内和机器人有部分视觉叠压（标签在 HTML 层，机器人在 SVG 里，lint 不查这种叠压）。
- L11 广角里，离场的机器人还能在中区左前方远处看到，很小，不影响。
