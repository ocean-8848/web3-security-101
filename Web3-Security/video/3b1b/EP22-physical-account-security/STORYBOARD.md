## 1. 概要

- **一句话核心观点**：密码学挡不住扳手。攻击者走最便宜的一环——找到人、找到人的手机号；防御就是两件事：别被关联（地址、身份、住址连不成线），别有单点（一个人、一张卡、一个地点不能单独放行大额资产或官方账号）。
- **支撑结构**：扳手攻击的成因（漫画） → 第一步是"关联"（公开信息 + 泄露数据 + 链上数据） → 数量趋势（Lopp 清单，法国） → 降低暴露、降低胁迫收益（多签 / 时间锁及其局限） → SIM 卡劫持 → 恢复流程是最弱一环 → 账号被盗放大到粉丝、员工手机号是特权凭证 → 关键人员防护 → 回到 SEC。
- **关键术语**：扳手攻击、关联（去匿名化）、SIM 卡劫持、号码转移锁、硬件安全密钥（FIDO2）、账号接管。
- **目标观众**：聪明、愿意花力气，但还不熟悉 Web3 安全的人。
- **预计时长**：7 分 52 秒（472.3 秒，10 个场景，58 个镜头）。

## 3. 叙事结构

1. **钩子**（hook）：2024 年 1 月 SEC 官方 X 账号发假"比特币 ETF 获批"，价格大幅波动；系统没被破解，只换了一张 SIM 卡。问题钉在左上角："从链上走到线下，防什么？"
2. **铺垫**（wrench）：一百万美元算力 vs 五美元扳手；比方（好锁 + 贴在网上的海报）及其不成立之处（链上余额一旦关联即公开）。
3. **逐步构建**：
   - link：攻击第一步是关联；三类材料；分两条路；数据泄露直接交出住址；图里没画熟人作案。
   - trend：Lopp 清单 74 → 106 → 170 → 147；法国 6 → 25 → 52，**25 × 2 = 50 < 52** 一步步算；家属也在攻击面；口径与低估。
   - coerce：降低暴露；2-of-3 三把钥匙全在家 = 没有多签；异地钥匙 + 48 小时时间锁；保护资产、不保护人。
   - simswap：SIM 卡劫持泳道图；关键设定是"短信可单独恢复"；两层防线。
4. **关键洞见**（weakest）：强度 = min(登录, 恢复)。攻击者不走前门。
5. **扩展**（social、people）：账号被盗放大到粉丝（Vitalik、Mandiant），员工手机号是特权凭证（FTX）；项目方关键人员清单与预案（清单放在最后）。
6. **回顾**（answer）：SEC 曾请 X 关闭该账号的二次验证 → 换卡 + 重置码。答案：别被关联、别有单点；成立条件：措施降低概率和收益，不保证人身安全。预告 23 集。
