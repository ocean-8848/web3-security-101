## 1. 概要（骨架）

- **一句话核心观点**：B 链看不到 A 链，桥只能相信某种证明（以及能升级桥合约的人）；证明机制被骗，桥上的全部资产就被骗走。评估一座桥，要数清放行一条伪造消息需要攻破几个**独立**的组织和数据来源。
- **支撑结构**：锁定-铸造流程与信任边界 → 四种验证方式各自信任谁（城市与提货单比方）→ 四类根因：私钥（Ronin，5/9 实为 2 道防线）、验证逻辑（BNB Token Hub、Wormhole、Poly）、初始化（Nomad）、存款伪造（Qubit）→ 代码没错也会被掏空（KelpDAO 单验证者 + RPC）→ 交易所充值也是一座桥 → 防御清单。
- **关键术语**：跨链桥、锁定-铸造、中继者 / 验证者、证明、信任边界、多签 / MPC、轻客户端、乐观证明、零知识证明、门限、独立性、消息执行器、白名单、速率限制、对账、假充值。
- **成立条件 / 例外 / 风险**：见第 6 节。
- **不确定之处**：Ronin 私钥获取方式按"公开报道称社会工程"；KelpDAO 的责任归属有争议并已进入诉讼，视频只陈述双方说法；Poly 的攻击手法只讲到"选择器撞上特权函数"的层面。
- **目标观众**：看过 EP05、EP09、EP10 更好。
- **时长**：7 分 16 秒（435.7 秒，8 个场景，48 个镜头）。

## 3. 叙事结构

1. **钩子**（hook）：Ronin 2022-03-23 两笔交易提走 173,600 ETH 和 2,550 万 USDC；9 个验证者 5 个签名放行；签名是真的。问题：桥凭什么相信另一条链？
2. **铺垫**（flow）：锁定 → 铸造（示例 100 USDT）；A→B 是信任边界；B 链验证三件事。
3. **逐步构建**：
   - verify：城市与提货单比方，四种验证方式各自信任谁；比方不成立处：金库最大、升级权限。
   - ronin：5/9 的门限，4 把在同一机构 + 1 个本应撤销的授权 → 一步步算出"独立防线只有 2 道"。
   - logic：BNB Token Hub、Wormhole、Poly → 四类根因 → 执行器白名单。
4. **关键洞见**（kelp）：合约代码完全没错，单验证者 + 被替换的 RPC 节点 → 桥只相信验证者，验证者只相信 RPC；没有第二个独立来源。
5. **延伸**（cex）：交易所充值也是一座桥，五种风险一一对应。
6. **回顾**（answer）：桥相信的是一份证明加上能升级它的人；数独立方（Ronin 2、KelpDAO 路径 1）；防线清单；成立条件；预告第 13 集。
