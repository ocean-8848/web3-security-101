# 3b1b 风格学习视频系列（对照实验）

> 来源：《Web3 安全学习手册》（升级后的 30 章版本）。每章一集，每集 5–8 分钟。
> 目的：与 [`../video/`](../video/README.md)（讲解页 + 渲染脚本，技术教学风格）做对比。两边**独立产出**，互不复用画面和脚本，只共用同一个声音（微软云希）。
> 状态：主线 30 集全部完成（共 215 分钟）。成片在 `output/`（不入库），每集的脚本与分镜在各自目录的 `STORYBOARD.md`。

## 1. 两条流水线的差异

| 维度 | `video/slides`（讲解页流水线） | `video/3b1b/`（本目录） |
|---|---|---|
| 风格 | 讲师白板课：步骤卡、源码高亮、硬字幕 | 3b1b：深色背景，一次只引入一个对象，图形承担论证 |
| 时长 | 每集 9–15 分钟 | 每集 5–8 分钟 |
| 画面工具 | 自写讲解页 + Playwright 录制 | HyperFrames（HTML + GSAP，逐帧确定性渲染） |
| 字幕 | 硬字幕 + 软字幕 | 不压字幕，另出 `.srt` |
| 声音 | 云希，逐句变化语速 / 音调 | 云希，固定语速 +5%、音调 +3Hz |
| 编号 | 新手册章号（EP01、EP03–EP12、EP27、EP28，EP04 = 第 04 章） | 新手册章号（EP01 = 第 01 章） |
| 时间轴 | 按步骤播放 | 配音是时钟：先合成旁白，再按每句的时间点排动画 |

## 2. 目录与制作流程

```
video/3b1b/
├── README.md                    本文件：系列规划与流程
├── tools/
│   ├── tts.py                   云希合成旁白 → narration.wav + cues.json，并把时间写回各场景
│   ├── subset_font.py           把 Noto Sans SC 裁成本集用到的字（woff2，约 180 KB）
│   ├── srt.py                   由 cues.json 生成字幕（未拆分版）
│   ├── pronounce.json           多音字读音替换表（只作用于配音）
│   ├── check_pron.py            用语音识别辅助检查多音字
│   └── burn_subs.py             画面缩到 88%，在下方条带压中文字幕，并写出同步 .srt
├── EP01-security-landscape/     一集一个 HyperFrames 项目
│   ├── STORYBOARD.md            概要、颜色语义、叙事结构、分镜表（逐镜）
│   ├── narration.json           旁白原文（按场景、按句）
│   ├── cues.json                每句旁白的起止时间（tts.py 生成）
│   ├── index.html               根合成：挂载场景 + 旁白音轨
│   └── compositions/*.html      每个场景一个文件
└── output/                      成品 MP4（已压字幕）与 SRT；output/raw/ 为无字幕原始渲染（均不入库）
```

做一集：

1. 写 `STORYBOARD.md` 与 `narration.json`。
2. 合成旁白并排时间轴（需联网，云希免费）：

   ```bash
   python3 Web3-Security/video/3b1b/tools/tts.py Web3-Security/video/3b1b/EP01-security-landscape
   ```

3. 写 `compositions/<场景>.html`。每个场景里的 `/*CUES*/…/*END*/` 由上一步自动填写；动画用 `at(句号, 句内比例)` 卡在旁白上。
4. 裁剪字体。源字体从 [google/fonts](https://github.com/google/fonts/tree/main/ofl/notosanssc) 下载（OFL 许可）：

   ```bash
   python3 Web3-Security/video/3b1b/tools/subset_font.py <NotoSansSC[wght].ttf> Web3-Security/video/3b1b/EP01-security-landscape
   ```

5. 检查、看帧、渲染：

   ```bash
   cd Web3-Security/video/3b1b/EP01-security-landscape && npx hyperframes check && npx hyperframes snapshot --at 10,60,120
   ```

   ```bash
   cd Web3-Security/video/3b1b/EP01-security-landscape && npx hyperframes render . -o ../output/EP01-security-landscape.mp4
   ```

   ```bash
   python3 Web3-Security/video/3b1b/tools/srt.py Web3-Security/video/3b1b/EP01-security-landscape Web3-Security/video/3b1b/output/EP01-security-landscape.srt
   ```

改旁白文字后重跑第 2 步：只重新合成改过的句子，场景时长自动更新。
