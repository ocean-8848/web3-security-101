# T06 运营安全自查清单

> 用途：每季度一次，覆盖密钥、签名流程、前端发布、终端、账号、供应链与第三方、监控与应急七个方面。由安全负责人组织，各项负责人填写，结果提交管理层。
> 配套：[18 钱包与密钥管理](../18-wallet-key-management.md)、[20 前端、DNS 与供应链](../20-frontend-dns-supply-chain.md)、[21 社工与内部人](../21-social-engineering-insiders.md)、[22 人身与账号安全](../22-physical-account-security.md)、[25 资金追踪与事后处置](../25-fund-tracing-response.md)、[A06 运营与密钥安全](../assessment/A06-operational-key-security.md)

## 使用方法

1. 每一项填写"状态"：✅ 通过 / ⚠️ 部分通过 / ❌ 未通过 / N/A 不适用。
2. "证据"一栏写可以复核的东西：截图、配置导出、日志链接、演练记录。没有证据的项按 ❌ 处理。
3. 标 ★ 的是**红线项**。任一红线项为 ❌，本季度结论为"不通过"，必须在 30 天内整改并复查。
4. 与上季度对比，变差的项单独列出。
