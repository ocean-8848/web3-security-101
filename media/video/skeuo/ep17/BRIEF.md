# ep17 分镜：节点、RPC 与验证者基础设施：你读到的是谁的链

统一视觉（画面、物件、颜色、字幕、术语卡、结束卡、版面分区、独立成片）见 `PIPELINE.md` 第 0 节，这里不重抄。讲稿 `script.json`，多音字表 `pron.json`。

## 1. 本集骨架

- **一句话核心观点**：你的系统从来没有直接读过链，它读的是某个节点、某个 RPC、某个索引器告诉它的链；验证者的风险出在自己的签名流程和所信任的中间人上。防线是按运营方数独立来源、超时不降级、冲突就暂停，以及"同一把密钥同一时刻只在一处"。
- **支撑结构**：
  1. 钩子：KelpDAO 事件，两个 RPC 节点被替换，只对验证者说谎，DDoS 干净 RPC 逼系统切换，约 2.9 亿美元；预测题：查询同一节点的监控能发现吗？
  2. 准确表述：数据分层（P2P → 节点 → RPC → 索引器 → 系统，外加网络路由）；Infura 2020；BGP 劫持三案；窗户比喻（不成立处：真实马路能换窗，很多系统只有一个 RPC）。
  3. 节点自己被蒙眼：P2P、日蚀攻击、重启时从地址表选对等节点、Geth 1.8.0 与锚点连接、"连接数正常 ≠ 独立"；DoS 是数据污染的前置步骤；8545 端口盗币、RPC 与 Engine API 不暴露。
  4. 验证者签名：罚没与双签、故障切换场景、三起罚没事件、防罚没数据 + 等待 + 分身检测；MEV-Boost relay：看不见就签、2023 年漏洞、修复、集中度快照。
  5. 防御（关键洞见）：节点按来源区别对待 → 比对不同运营方；多源、不降级、冲突暂停、链头比对与客户端多样性；局限：同一上游。
  6. 按角色一件事 + 用户侧 → 回答开头 → 收束。
- **关键术语**：RPC 节点、跨链验证者、DDoS、索引器、节点客户端、Geth、共识 bug、分叉、BGP 劫持、DNS、SDK、P2P 网络、对等连接、日蚀攻击、地址表、锚点连接、JSON-RPC、Engine API、JWT、罚没、双签、slot、防罚没数据、epoch、分身检测、MEV-Boost、relay、构建者、提议者、法定数、客户端多样性。
- **成立条件、例外和风险**：窗户比喻只说明"你看到的是转述的街道"，不成立处是真实马路能换一扇窗（seg2 L20–L21）。"多源校验"只在来源按运营方真正独立时成立；所有来源接在同一上游时数量再多也没用（seg5 L16、seg6 L9）。分身检测是最后一道防线，不是保证（seg4 L11 画面写"最后一道"）。日蚀攻击是研究结论，资料未查到公开归因于日蚀、造成资金损失的案例（seg3 L8 来源卡写"Marcus 等论文"，画面不画损失）。
- **不确定之处**：开场"放行了一条消息"按资料"使验证者接受一条不存在的跨链消息"改写；资料另写责任归属有争议、与 KelpDAO 的单验证者配置有关，配音不展开，画面不给任何一方打叉。金额口径"约 2.9 亿美元"取 LayerZero 声明（媒体统计约 2.92 亿）。8545 端口事件资料写"38,642 ETH，超过 2,000 万美元"，配音写"约 3.8 万个 ETH"，不念美元；来源卡写"BleepingComputer 报道（360 Netlab 发现）"。"同一网段"指资料里的同一 /24，画面小字写"同一 /24"。Lido、SSV 两起只念年月，人数 20、39 只上屏。74% 是 2026 年 11 月 8 日 relayscan.io 单日快照，波动大，来源卡写清"单日快照"。

## 2. 世界与主角（全片固定）

一个连续的等距世界，叫"**读链大街**"。一条浅灰石板路沿 u（左→右）贯穿：最左是**跨链桥头**（开场事件），往右依次是**数据管线街**（分层 + 路由 + 窗户比喻）、**节点小屋**（P2P、日蚀、端口）、**验证者机房**（罚没 + relay），最右是**仲裁台**（防御 + 收尾）。全片的主角是 kit `rpc`（"RPC 节点"）：它在每个区出现，正常时青蓝灯 + 信号弧，被替换或被污染时 `state` attacker（红），被 DDoS 打掉时 broken（红虚线框 + 红叉）。"自动切换"在全片都画成同一种东西：E16 `forkSwitch`（扳道器，把数据流扳到另一路）。数据流一律用 E01 `pipe` + 管内流动虚线，假数据用红色 E01 `letter`。

## 4. 各段分镜（按句写；句号见 timing.json 的 lines，从 0 开始）

### seg1 ① 只对你说谎
目标：观众能说出"2026 年 4 月，两个 RPC 节点被替换、只对验证者说谎，干净 RPC 被打掉后系统自动切到它们，损失约 2.9 亿美元"，并带着"监控查同一节点能不能发现"往下看。
副标题：两个节点，只对验证者说谎
