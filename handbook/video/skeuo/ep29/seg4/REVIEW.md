## 创作取舍
- 世界布局沿用 seg3b（关间距 480、旗在路后侧、RPC 支线在 ⑤ 后），开场镜头 = seg3b 的 PAN，事件卡位置也一样，方便接缝。seg2 的 `layout.mjs`（间距 640、支线在前侧）和 seg3a/3b 实际用的布局不一致，需要总导统一。
- 三张"共同点卡"做成 ②④⑦ 岗亭屋顶上的告示牌（两腿 + 背板 + 面板），L7–L9 绕上边翻面，背面是原则；第二行文字按词出现。
- L5–L6 比喻放在远离道路的"广场"：保险柜放大 1.45 倍（约占画面高 60%），公章和文件放大 1.85 倍；画面停留约 11 s（37.8–48.6），盖章后静止约 1.9 s。

## 自审发现 → 修改
1. 钥匙挂在柜后壁，透视被侧壁挡住 → 挂到开口内上格，去掉金条，让钥匙成为柜内唯一的金色物件。
2. 比喻广场在终景里露出来 → 移到 v = 3300。
3. 终景 k = 0.476 时告示牌文字不到 30 px → 镜头只框三块牌 + 关卡，k = 0.615（正文约 37–55 px）。
4. 原则二的 RPC 在牌二背后被挡、标签叠在牌上 → 两路来源移到 ⑤ 前侧，"≠"贴地，"拒签 · 不自动切换"挪到左侧。
5. rpc2 / 信标预设 svgOrigin 导致位置错 → 删掉预设，改为出现时生长。
6. L2/L3 主物件太小 → 柜台和信封放大 1.35 倍，四个"独苗"放大 1.4 倍、间距拉开，标签上下交替。
7. 标签被遮挡或进入字幕带："签出：攻击者想要的"被事件卡挡住，"链下 / 链上"进了字幕带，"一断就没有输入"留到了后面的镜头 → 已全部移位或按时淡出；终景淡出旗名、① 和区块链标签，避免被裁切。
8. check：veil 全屏遮罩错误 → 删掉遮罩；#stk-tag 初始隐藏改用 CSS；事件卡小字改为 ≥ 28 px。
