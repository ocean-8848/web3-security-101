# seg4「④ 一个卡住全部」自审

## 结构
- `src/layout.mjs`：拍卖台 = seg1 `AUCTION_ZONE`（已对齐，`ALIGNED: true`），其余物件按拍卖台地面点偏移摆放，镜头从左到右平移：DoS 路牌 + 被封住按钮的合约 → 拍卖台（A 拒收合约、B 出价、取件柜）→ 快递比喻（12 个包裹代表 100 个）→ 四种 DoS（分发线 + 区块 gas 油表、冻结收件人、天平、以太坊 / TRON 两条链 + 沙漏）→ Akutars。
- `src/build-story.mjs` 生成 `compositions/story.html`；时间全部用 `wordAt` / `lineAt`。
- 段首 0–1.6 s 章节标题卡"④ 一个卡住全部 · 外部调用导致的拒绝服务"，飞进胶囊。

## 术语卡（左上 48,120；同一时间只一张）
| 时刻 | 术语 | 定义 |
| --- | --- | --- |
| L3 receive | receive 函数 | 合约收到 ETH 时会执行的函数 |
| L12 | 区块 gas 上限 | 一个区块能容纳的 gas 总量 |
| L13 | 累计奖励因子 | 只记每份额累计多少奖励 · 领取时再算 |
| L16 | 强制转入 | 不经过 receive · 硬把 ETH 塞进合约 |
| L20 | NFT | 不可互换的代币 · 每一枚都不同 |
"拒绝服务""拉取式支付"由配音当场解释，不出卡；"wei"写在场景标签"强制转入 1 wei"旁边。

## 自审过程（逐句中点 + 0.8 s + 段尾 0.5 s 抽帧）
第一轮发现并已修：
- 各区距离太近，相邻区的物件漏进画面（拍卖台镜头里露出被封的合约、包裹镜头里露出油表、Akutars 镜头里露出沙漏）→ 各区拉开（四种 DoS 起点 +700，Akutars 再 +1100）。
- 包裹太小 → 包裹放大 1.35 倍、镜头推近。
- Akutars 合约机器铭牌 "AKUTARS" 超宽（负宽度 rect 报错）→ 铭牌只作质感写 "AK"，要读的字用标签"Akutars 合约"。
- 取件柜标签"单独失败 · 跳过"压住小取件柜 → 小取件柜移到收件人右侧。
- 提款闸门的挂锁、金币挂锁开场就显示 → 改成到 L22 / L23 才长出来。
- "11539.5 ETH"大字先压住缺陷 1 的拍卖台，后来又压到字幕卡 → 放到金条下方，并把 Akutars 镜头整体上移 80 px。
- "钱还在"标签压住路牌 → 路牌左移。
