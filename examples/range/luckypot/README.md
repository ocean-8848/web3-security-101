# LuckyPot（审计靶场 2）

> ⚠️ 警告：本项目只用于本地学习。不要把它部署到任何公开网络。

## 协议说明（审计时把这一节当作客户文档）

LuckyPot 是按轮次运行的抽奖合约。

- owner 开启一轮。一轮持续固定时间。
- 玩家按固定票价买票，一次可以买多张。每张票的中奖概率相同。
- 协议从每笔购票款中收取手续费。
- 销售结束后，任何人都能调用 `draw()`。开奖结果不能被任何人预测或操纵。
- 每轮最先买票的 3 个地址（早鸟）各得奖池 1% 的奖金。
- 中奖者调用 `claimPrize()` 领奖。
- owner 可以在销售期内取消一轮。如果销售结束 1 天后票数仍不足，任何人都能取消。
- 轮次取消后，玩家按票价全额退款。
