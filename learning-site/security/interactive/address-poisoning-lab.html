地址投毒比对

地址投毒（Address Poisoning）：攻击者生成一个首尾字符与你常用地址相同的地址，再往你的交易记录里塞一笔小额或零额转账。你下次从记录里复制地址，就可能复制到攻击者的地址。配套章节：19 用户侧诈骗、23 托管与交易所运营。

1. 从交易记录里复制地址

场景（示例）：你上周给合作方转过 50,000 USDT。今天要再转一次。钱包只显示地址的前 6 位和后 4 位。点击你认为应该复制的那一行。

4. 防御清单

用户

  1. 不从交易记录复制地址。用地址簿或收款方从安全渠道发来的地址。
  2. 核对完整地址，至少再核对中间的一段字符。
  3. 大额转账先发一笔测试金额。测试之后仍然从地址簿取地址：投毒常在测试转账之后几分钟内出现。
  4. 钱包里隐藏零额转账和未知代币。

交易所 / 钱包产品

  1. 提币地址白名单，新增地址设置冷却期。
  2. 提币前比对：目标地址与用户历史地址"首尾相同、中间不同"时强提示。
  3. 交易记录默认折叠零额转账和非白名单代币。
  4. 把已知投毒地址加入风控名单，并与威胁情报共享。
