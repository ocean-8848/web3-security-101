九项目对比矩阵

把比特币、以太坊、BNB Chain、TRON、Mantle、XRPL、USDT、USDC、Solana（另加 Base 参照）放进同一张表。筛选维度、排序、并排对比，再用"用途匹配器"验证 X08 第 9 节的选链倾向。

怎么玩
  1. 点一个预设场景，或者自己勾选维度组（技术 / 费用 / 商业 / 权力 / 监管）。
  2. 在"排序"里选一个维度。矩阵按它重新排列；点表头的定性维度也能排序。
  3. 勾选 2–3 个项目。下方出现并排对比卡和雷达图。
  4. 在"用途匹配器"里选一个场景。倾向的项目在矩阵中高亮，并给出理由和风险。
  5. 每个格子下方的小字是时间点和来源章节。点击可回到原文核对。

观察要点

  • 按"出块间隔"或"最终性"排序，再切到"权力"维度看"出块者量级"。越快的链，出块者通常越少。雷达图里找不到"性能"和"去中心化"同时为 5 分的项目。
  • 按"单笔 USDT 成本"排序，TRON 排在最贵的一端。切到"支付"场景，TRON 仍是倾向之一。原因不在单价，而在网络效应（X03 第 1.2 节）。
  • 按"收入规模量级"排序，最上面是 USDT，不是任何一条链。注意各行口径不同：利润、链上费用、REV 不能直接相加或比较。
  • 选中 Mantle 和 Base 对比：两者都是以太坊 L2，Stage 和收入来源却不同。"ZK 证明"没有让 Mantle 越过 Stage 0。
