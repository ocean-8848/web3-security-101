一笔合约调用的 data 字段 = 4 字节函数选择器 + 按 32 字节切开的参数。本实验把 calldata 拆开，告诉你每一段字节是哪个参数；也能反过来，由函数和参数生成 calldata。

怎么玩
  1. 点一个"示例"按钮，或把区块浏览器里的 Input Data 粘贴到输入框。
  2. 看"字节切分"：每行 32 字节，颜色对应右侧参数表。鼠标停在参数上，对应字节会加框。
  3. 看风险提示：无限授权、无滑点保护会标红。
  4. 切到下方"编码"：选函数、填参数，生成 calldata，再送回解码器验证。

观察要点

  1. 选择器 = keccak256(签名) 的前 4 字节。transfer(address,uint256) → 0xa9059cbb。03 章的 transfer 示例共 4 + 32 + 32 = 68 字节。
  2. 地址和数字都被补齐到 32 字节。地址左侧补 12 个零字节；数字左侧补零。所以 calldata 里有大段的 0。
  3. 动态数组分两处存放。参数区只放一个"偏移量"（例如 0xa0 = 160 字节）；真正的长度和元素放在末尾。
  4. approve 的数额是 2²⁵⁶ − 1，就是无限授权。被授权的合约以后可以随时转走你这种代币的全部余额。
